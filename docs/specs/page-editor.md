# 页面装修编辑器约束

- 当后台画布复用公开商城组件时，必须同步提供该组件在线上布局依赖的 React Context。当前 `PublicHome` 会渲染使用 `usePublicCart` 的 `ProductCard`，因此编辑器预览必须位于 `PublicCartProvider` 内；违反此约束会导致页面打开或拖入商品组件时发生客户端异常。
- 后台预览中的购物车 Context 只用于满足共享组件的运行环境，不代表预览可以提交订单或写入线上业务数据。
- 公开首页、自定义 `StorePage` 和后台画布统一使用 `PublicHome`。新增或修改公开页面组件时必须同时验证这三个入口，禁止另建只服务自定义页的平行渲染路径。
- 页面草稿可以引用当前店铺的草稿页面，便于先搭建完整导航；发布时必须重新校验页面目标已经发布，未发布目标要阻止发布并显示页面名称。
- 店铺专属模板只能覆盖 `draftJson`，不得隐式修改 `publishedJson`。缺失内容页可以创建草稿；相同 slug 的现有页面必须保留，是否发布由管理员明确操作。
- 良丞首页模板向所有店铺的当前主页开放；普通页面必须同时由编辑器隐藏入口并由 Server Action 拒绝。应用模板只允许修改当前店铺主页草稿和创建当前店铺缺失的内容页草稿。
- 商品分组广告的分类集合只来自已保存的页面配置。公开分组路由必须按当前店铺和已发布页面查找广告项，不得接受 URL 提供的分类 ID 作为数据权限来源。
- `productSearch` 是独立装修组件；需要覆盖首屏时使用 `heroOverlay` 样式并放在 `heroCarousel` 前。禁止在轮播渲染器内隐式生成搜索框，否则组件无法独立移动、编辑或删除。
- `heroCarousel.slides` 的持久化输出只包含 `imageUrl` 与非展示型 `alt`。旧 V4 的标题、副标题和链接只作为兼容输入忽略；公开页不得渲染轮播文案、跳转、渐变或阴影。
- 首页名片只按同店、启用账号的 `STORE_ADMIN` / `EMPLOYEE` 有效 `ref` 解析；无效或缺失 `ref` 回退店铺默认名片。普通客户资料不得参与首页名片选择。
- 个人名片和店铺默认名片的微信号由管理员或员工真实录入且必填；禁止模板提供伪造默认值。客户设置只允许昵称、联系电话、头像和密码，旧名片字段及客服二维码写入必须由服务端拒绝。
- 名片电话和微信控件必须在鼠标悬停与键盘聚焦时显示完整联系方式，并把实际值写入无障碍标签；电话保持 `tel:` 行为，微信保持复制行为。
- 轮播分页控件运行在公开 H5 和后台共享画布中，调用平滑滚动前必须兼容不实现 `Element.scrollTo` 的旧 WebView；违反此约束会在点击分页时触发整页客户端异常。
- 轮播滚动事件必须在同步回调内快照 `clientWidth` 与 `scrollLeft`，状态更新只接收计算后的普通数字；禁止在延迟执行的状态更新函数中持有 React 事件对象，否则 `currentTarget` 失效会触发客户端异常。
- 公开首页和公开自定义页的多图首屏轮播每 5 秒自动切换并在末页回到首页，悬停和手动操作会暂停或重新计时；后台装修画布必须关闭自动播放，避免编辑过程中画面自行变化。
