# APP 代客开单权限与归属

- APP 下单权限必须由服务端根据当前 APP 会话、账号启用状态、角色和店铺归属重新判定；禁止信任客户端传入的角色或仅凭 `/admin/login` 后台会话授权。
- 公开目录必须分别表达 `anonymous`、`customer`、`employee`、`storeAdmin` 和 `forbidden`；`customerActive` 只表示本店客户资料可用于收藏，禁止用它代表员工或管理员的下单权限。
- 同店启用员工代客开单时，客户姓名和手机号必填，`customerId` 为空，来源与负责人均为当前员工，客户线索的最近员工同步为当前员工；违反会造成员工订单不可见或归属错误。
- 同店启用店铺管理员代客开单时，客户姓名和手机号必填，`customerId`、来源和负责人均为空；违反会把店铺默认订单错误归到个人。
- 客户下单必须继续使用本店已激活客户资料，并保留有效 `ref` 的来源、负责人和客户归属更新；员工和管理员代客开单必须忽略 URL 中的 `ref`。
- 幂等重试只能返回同店且与当前下单身份相符的既有订单；标识冲突必须拒绝，禁止跨店或跨员工复用订单结果。
